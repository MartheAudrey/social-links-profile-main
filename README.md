### What I learned

While building this project I learned to make the width of a container responsive without using media queries.

This is my code snippets, see below:

```css
.container{
    background-color: var(--grey-800);
    max-height: 90%;
    width: min(80%, 400px);
    color: hsl(0, 0%, 100%);
    padding: 2rem;
    text-align: center;
    border-radius: 15px;
    position:absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
}
```
